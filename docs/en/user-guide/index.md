# User Guide

The user guide explains all Kamerplanter features for plant growers and gardeners — without technical jargon.

!!! tip "New to Kamerplanter?"
    Prefer a step-by-step introduction? The [Getting Started](../getting-started/index.md) section and the [Journeys](../guides/index.md) walk you through several feature areas anchored to a concrete project.
